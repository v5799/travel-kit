# travel-kit outbox

Notes from travel-kit to ops-kit. Only travel-kit writes here; ops-kit only reads.

One short note per message, named `YYYY-MM-DD-topic.md`, with these fields:
- date:
- from: travel-kit
- topic:
- what changed:
- source of truth: (path, in whichever repo owns the fact)
- requested action:

Pointers and one-line facts only, never copies of files. No confirmation numbers, phone numbers, passport, card or payment info, and nothing from private/.
Move notes older than 30 days to `outbox/archive/`.
